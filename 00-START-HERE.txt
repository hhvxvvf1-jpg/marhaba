MARHABA — طريقة الرفع إلى GitHub
=================================

1) فك الضغط عن هذا الملف في مجلد على Windows.
2) تأكد أن Git for Windows مثبت: https://git-scm.com/download/win
3) شغّل Publish-MARHABA.bat بالنقر المزدوج.
4) إذا طلب الاسم والبريد، أدخل اسمك والبريد المرتبط بحساب GitHub.
5) أكمل تسجيل الدخول إلى GitHub في المتصفح إذا ظهر الطلب.
6) انتظر ظهور SUCCESS ثم افتح:
   https://github.com/hhvxvvf1-jpg/marhaba

الملفات داخل الحزمة:
- MARHABA-deploy-clean.zip: ملفات التطبيق النظيفة.
- Publish-MARHABA.ps1: سكريبت الرفع.
- Publish-MARHABA.bat: تشغيل السكريبت بالنقر المزدوج.

ملاحظات:
- السكريبت لا يستعمل force push، ويتوقف إذا تعذر الرفع.
- قاعدة البيانات المحلية ومفتاح الجلسات وسجل Git القديم غير مشمولين.
- رفع الكود إلى GitHub لا يجعل الموقع مباشراً؛ التطبيق يحتاج استضافة Node.js
  مع مساحة تخزين دائمة لقاعدة SQLite، أو نقل قاعدة البيانات إلى خدمة خارجية.
